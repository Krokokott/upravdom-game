# Управляющий. Первый год

Карточная мини-игра про новый дом в двух режимах:

- «Какой ты управляющий» — первый год директора управляющей компании, 20 решений, четыре шкалы, можно проиграть;
- «Какой ты житель» — тест из 20 ситуаций в чате дома. Проиграть нельзя, в конце выпадает один из 8 типажей соседа.

Работает как Telegram Mini App и как обычная веб-страница. Ссылка `https://t.me/Brus_home_bot?startapp=resident` (или `#resident` в браузере) сразу открывает режим жителя.

Неофициальный фан-концепт. Персонажи и ситуации вымышлены.

## Структура

- `src/shell.html` — разметка и стили
- `src/cards.js`, `src/cards2.js` — колода управляющего (текст, варианты, влияние на шкалы)
- `src/resident.js` — колода жителя (100 ситуаций) и 8 типажей
- `src/engine.js` — логика игры и интеграция с Telegram
- `build.py` — собирает всё в `index.html`
- `index.html` — готовая игра, её и публикует GitHub Pages

После любых правок в `src/` пересоберите игру:

```bash
python build.py
```

Баланс: `node tools/sim.js` для управляющего и `node tools/sim-resident.js` для жителя. Второй скрипт проверяет id карточек и очки типажей, а затем прогоняет 20 000 партий со случайными ответами. Каждый типаж должен выпадать в 8–17% партий.

## Публикация на GitHub Pages

1. Создайте на github.com пустой публичный репозиторий, например `upravdom-game`.
2. Отправьте туда этот проект (`git push`).
3. В репозитории откройте Settings → Pages → Source: Deploy from a branch, ветка `main`, папка `/ (root)`.
4. Через минуту игра откроется по адресу `https://<логин>.github.io/upravdom-game/`.

## Подключение к Telegram

1. В @BotFather: `/newbot` — имя и username бота. Не используйте название чужого бренда в username.
2. `/newapp` — выберите бота, укажите название, описание, картинку 640×360, ссылку на игру с GitHub Pages и короткое имя, например `year`.
3. BotFather выдаст ссылку вида `https://t.me/<бот>/year`. Впишите её в `APP_LINK` в начале `src/engine.js`, выполните `python build.py` и снова отправьте изменения в репозиторий. После этого кнопка «Поделиться» будет вести прямо в мини-приложение.
4. По желанию: `/setmenubutton` — кнопка запуска игры в чате с ботом.

Токен бота для этой версии не нужен: сервера у игры нет.
